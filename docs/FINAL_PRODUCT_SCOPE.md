# Final Product Scope — v3.0.0

## Product promise

Turn e-commerce support emails into explainable, policy-safe recommended actions using authoritative Shopify order facts while keeping humans in control.

## Supported workflows

1. Where is my order?
2. Return / Refund
3. Missing / Wrong Item
4. Cancel / Modify

## Final application screens

- Overview
- Attention Queue
- Support Inbox
- Cases
- Case Workspace
- Automation Lab
- Customer Signals
- Policies
- Orders
- Integrations
- Audit Log
- Settings

## Differentiators

- Review-first AI
- Decision Trace separating AI, Shopify, policy, deterministic rules, and human approval
- Human corrections stored as evaluation/audit data
- Safe simulation environment with processing timings
- Operational customer signals derived from actual persisted cases
- Arabic/English interface with RTL/LTR support
- Live/Demo separation
- No automatic email sending
- No Shopify mutations

## Reviewed manual Gmail sending

An operator-reviewed Gmail Draft may be sent manually only when the feature is explicitly enabled. Automatic sending is not part of the product.

## Explicit non-goals for this release

- refunds/cancellations executed in Shopify
- autonomous customer email sending
- inventory/warehouse automation
- carrier API automation
- sentiment analytics
- discounts/store-credit execution
- arbitrary workflow builder
- omnichannel/WhatsApp/voice
- billing/multi-tenant SaaS
