# Brand asset slot

Replace `logo.svg` with the final project logo when it is ready.

Recommended: square SVG with transparent background, viewBox `0 0 64 64` or equivalent.
The UI keeps the product name as text next to the mark, so the logo works best as an icon/mark rather than a full wordmark.

If you use PNG instead, update `logoPath` in `frontend/js/brand.js`.
